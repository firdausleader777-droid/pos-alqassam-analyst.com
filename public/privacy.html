Kebijakan Privasi POS Al-Qassam Analyst

Google Play Store & Android AAB Compliance
Terakhir diperbarui: 15 Oktober 2026

Selamat datang di POS Al-Qassam Analyst. Kami berkomitmen untuk menghormati dan melindungi privasi serta keamanan data operasional toko, data produk, dan informasi kasir Anda. Dokumen Kebijakan Privasi ini menjelaskan bagaimana data diproses saat Anda menggunakan aplikasi kami di berbagai perangkat (Komputer Kasir PC, Tablet, dan Smartphone Android).

Prinsip Utama Privasi Kami:

POS Al-Qassam Analyst TIDAK MENJUAL, tidak menyewakan, dan tidak membagikan data transaksi bisnis, data stok, maupun informasi keuangan Anda kepada pihak ketiga pengiklan manapun. Seluruh basis data disimpan pada browser lokal perangkat Anda atau pada infrastruktur database Supabase privat yang Anda konfigurasi sendiri.

1. Informasi dan Data yang Diproses

Aplikasi ini memproses data operasional toko yang Anda masukkan secara mandiri, meliputi:

  • Data Produk & Inventaris: Nama produk, SKU, kode barcode, kategori, jumlah stok, stok minimum (alert), harga modal (beli), harga eceran, dan harga grosir.
  • Data Transaksi Penjualan: Waktu transaksi, nama kasir bertugas, identitas perangkat (PC 1, PC 2, Tablet 3, atau HP Android), daftar item belanja, total pembayaran, dan rincian laba kotor.
  • Data Restock & Pemasok: Kontak supplier, riwayat pembelian barang masuk, dan nilai modal awal tahunan.
  • Data Akun Pengguna: Nama staf, username, dan daftar hak akses menu yang telah disetujui oleh Administrator toko.

2. Penggunaan Izin Perangkat Android (Permissions)

Aplikasi POS Al-Qassam Analyst membutuhkan izin berikut untuk menjalankan fungsinya secara optimal pada sistem operasi Android:

  • Izin Kamera (android.permission.CAMERA):
    Hanya digunakan saat fitur Barcode Scanner aktif untuk mendeteksi dan membaca kode batang (barcode) pada kemasan produk secara cepat melalui kamera perangkat. Aplikasi tidak pernah merekam video, mengambil foto pribadi pengguna, atau mengunggah rekaman kamera ke server luar.
  • Izin Internet & Jaringan (android.permission.INTERNET & ACCESS_NETWORK_STATE):
    Digunakan semata-mata untuk menghubungkan sistem kasir ke server database cloud Supabase milik Anda agar sinkronisasi multi-device berjalan secara realtime di antara PC kasir, tablet, dan ponsel.
  • Penyimpanan Lokal (Local Storage / Cache):
    Menyimpan pengaturan printer thermal, preferensi tampilan, dan cadangan transaksi secara offline agar kasir tetap dapat beroperasi meski koneksi internet terputus sementara.

3. Arsitektur Multi-Device & Keamanan Data

Sistem POS Al-Qassam Analyst dirancang dengan standar keamanan tinggi:

  • Transmisi Terenkripsi: Semua komunikasi data antara perangkat Android dan database cloud Supabase menggunakan protokol HTTPS dan WSS (WebSockets Secure) dengan enkripsi TLS 1.3.
  • Row Level Security (RLS): Akses basis data PostgreSQL dilindungi kebijakan Row Level Security untuk mencegah akses tidak sah dari pihak luar.
  • Identifikasi Perangkat: Setiap komputer kasir, tablet, dan smartphone memiliki tanda pengenal unik lokal (Device Tag) sehingga setiap nota penjualan dapat diaudit dengan jelas siapa kasirnya dan dari perangkat mana transaksi tersebut dibuat.

4. Hak Kontrol dan Penghapusan Data Pengguna

Sebagai pemilik toko (Administrator), Anda memiliki kendali penuh 100% atas data Anda:

  • Anda dapat mengekspor seluruh basis data ke dalam file Excel (.xlsx) kapan saja melalui menu Import / Export Excel.
  • Anda berhak menghapus atau mereset seluruh data toko secara permanen melalui tombol reset database yang dilindungi kata sandi di dalam aplikasi.
  • Jika aplikasi dicopot pemasangannya (uninstall) dari smartphone Android Anda, data lokal yang tersimpan di memori perangkat akan otomatis terhapus oleh sistem Android.

5. Kepatuhan Anak (COPPA / GDPR)

Aplikasi ini ditujukan untuk kebutuhan bisnis, kasir, dan manajemen toko retail/grosir, dan tidak ditujukan untuk anak-anak di bawah usia 13 tahun. Kami tidak secara sengaja mengumpulkan informasi dari anak-anak.

6. Perubahan Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu untuk menyesuaikan dengan fitur baru atau regulasi Google Play Store. Perubahan akan selalu diperbarui pada halaman ini dengan tanggal revisi terbaru.
